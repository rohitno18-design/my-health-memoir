## How this file gets updated

`/learn` updates this automatically at the end of every session:
- moves **Next lesson** forward
- adds a row per lesson taught
- increments the counters
- sets **Review due** every 5th session

If a row says ⬜ pending in the "Logged" column, that means the lesson was
taught but Rohit hasn't written it back in his own words yet in
`LEARNING-LOG.md`. That's the step that makes it his — chase it.
