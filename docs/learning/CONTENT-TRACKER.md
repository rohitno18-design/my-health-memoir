## The rule on backlog size

A growing backlog is **the system working**, not failing. Learning at 3/day and
posting at 3–5/week means the library grows by design — that's what guarantees
you never script from nothing.

Only worry if a lesson has sat in the backlog for 30+ days *and* you still feel
strongly about it. That means something is blocking filming, not choosing.
