# The Curriculum

**275 lessons. 16 parts. At 3 lessons/session, about 92 sessions.**

This is the syllabus, not the teaching. Each line is one lesson; the actual
lesson gets delivered live in a `/learn` session and written into `BOOK/`.

Lesson numbering is permanent — never renumber. Add new lessons at the end of
a part with the next free number.
